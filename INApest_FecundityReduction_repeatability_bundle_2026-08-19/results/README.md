# Results directories

- **archived/** — original evidence generated during the FecundityReduction implementation work.
- **latest_rerun/** — same validation workflow rerun against the current later source defaults. The six core evidence CSVs are byte-identical to archived versions.
- **native_serial_reproduction/** — current-source serial reproduction of the scientific parameterisation and demonstration tables, independent of host core count.
- **webr_exact_rerun/** — exact one-core rerun using the retained WebR environment.

The demonstration outputs are implementation tests, not calibrated species predictions.
